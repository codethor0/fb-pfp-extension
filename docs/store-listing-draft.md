# Store listing text (as entered in the Chrome Web Store draft)

**Name:** fb-pfp: Profile Picture Rotator

**Short description:** Review or change your own Facebook profile picture using local photos. No accounts, servers, or tracking.

**Category:** Social Networking

**Language:** English

**Description:**

fb-pfp is a free, open-source Chrome and Brave extension for preparing or changing your own Facebook profile picture using photos you choose.

Import pictures from your device and choose random rotation or rotation without repeats. Prepare for review opens Facebook's profile-picture dialog without clicking Save. Change now requires explicit confirmation before it attempts to save your picture.

Optional daily scheduling prepares a photo for review. It never publishes automatically.

Imported photos are resized and processed locally, which removes embedded camera metadata. Images are stored in your browser. When a photo is placed into Facebook's upload control, Facebook may receive it before you click Save.

No developer-hosted backend, advertisements, analytics, or subscription fees.

Requires a Facebook account you own and the English-language Facebook interface. Facebook interface changes may affect compatibility. Automation may be restricted by Meta's terms.
