# Free distribution

## Source code

GitHub source releases and manual Load unpacked installation cost nothing. A single Manifest V3 package targets both Chrome and Brave. Do not include any imported pictures or browser state in the ZIP file.

## Browser stores

A Chrome Web Store developer account requires a one-time registration fee and a publication review. An extension that knowingly violates another service's terms may be rejected or removed. Confirm the relevant Facebook terms and Chrome Web Store terms before investing in a store release.

Brave supports Chromium extensions. A separate Brave listing is not necessary for local installation or for installations supported through the Chrome Web Store.

## Store readiness

This version is a local-testing source release. It does not claim Chrome Web Store approval. The planned public listing should provide this project's privacy policy, a focused description, no misleading automation guarantees, and transparent disclosure of Facebook website access.
