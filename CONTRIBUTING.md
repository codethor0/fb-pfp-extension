# Contributing

Keep changes minimal and verifiable. Submit focused pull requests with a failing test for every bug fix. Preserve the privacy model and restricted permissions. Do not add personal photos, account screenshots, debugging profiles, cookies or secrets to Git or pull requests.

Run `npm run check` before every pull request. Browser-specific changes also need the offline Chromium DOM smoke test and a documented real-browser manual check. Do not broaden website access or introduce a network service without explaining why it is needed and reviewing the privacy policy.

The maintainer handles publication through their own account and command line. Do not force-push protected branches or alter released tags.
